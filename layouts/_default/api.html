API Documentation

Free, open API for password analysis and breach statistics

Base URL

https://muddy-scene-9bdf.haveubeenpwned.workers.dev

All API endpoints are free to use with no authentication required. Rate limits apply (100,000 requests/day).

Endpoints

POST /check

Interactive password check - returns HTML awareness page (perfect for curl usage)

Request Body:

Parameter Type Required Description
password string Yes The password to analyze

Example Request:

curl -X POST https://muddy-scene-9bdf.haveubeenpwned.workers.dev/check \ -H "Content-Type: application/json" \ -d '{"password": "MyP@ssw0rd123"}'

Response:

Returns HTML awareness page with password analysis and security tips

POST /analyze

Analyze password metadata (for programmatic use) - returns JSON

Request Body:

Parameter Type Required Description
length integer Yes Password length
has_number boolean Yes Contains numbers (0-9)
has_special boolean Yes Contains special characters

Example Request:

curl -X POST https://muddy-scene-9bdf.haveubeenpwned.workers.dev/analyze \ -H "Content-Type: application/json" \ -d '{"length": 12, "has_number": true, "has_special": true}'

Response:

{"status": "ok"}

GET /stats

Get aggregated password statistics - returns JSON

Example Request:

curl https://muddy-scene-9bdf.haveubeenpwned.workers.dev/stats

Response:

Bash Script Example

Complete script to check a password from command line:

#!/bin/bash # Simple password check PASSWORD="MyP@ssw0rd123" curl -X POST https://muddy-scene-9bdf.haveubeenpwned.workers.dev/check \ -H "Content-Type: application/json" \ -d "{\"password\": \"$PASSWORD\"}" \ -o awareness.html echo "Results saved to awareness.html" open awareness.html # macOS # xdg-open awareness.html # Linux # start awareness.html # Windows

Privacy & Data Collection

  • Passwords are never stored or logged
  • Only anonymized metadata is collected (length buckets, complexity, time of day)
  • Data cannot be linked back to individual users
  • All data is used for research and displayed publicly on the Research page
