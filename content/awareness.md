# Why this matters

You just entered your password into a random website.

This campaign demonstrates how easily credentials can be collected through trust and familiar design patterns.

## Important

- Your password was NOT stored in plaintext
- Only a partial anonymous hash was processed
- This was an educational awareness campaign

## What you should do now

If this was a real password you still use:

1. Change it immediately
2. Never reuse passwords
3. Use a password manager
4. Enable MFA wherever possible

## Remember

Even professional-looking websites can be malicious.
